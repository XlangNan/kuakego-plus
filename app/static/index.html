🔎 资源搜索（PanSou）

添加订阅 / 监控时，可以直接搜索夸克资源并选择。需要你自己部署一个 PanSou，本项目只调用它的接口，不内置。
填「只有接口」版本的地址（默认端口 8888），不是带网页的版本。和本程序在同一个 compose 里时可写 http://pansou:8888。
高级：指定频道 / 插件（留空 = 用 PanSou 自己的默认配置）
怎么部署 PanSou？
最简单的方式（只要接口）：
docker run -d --name pansou -p 8888:8888 \ -e ENABLED_PLUGINS=hunhepan,pansearch,quark4k,quarksoo,sousou,labi,zhizhen,duoduo,muou,wanou \ ghcr.io/fish2018/pansou:latest
· 然后在上面填 http://服务器IP:8888，点「测试连接」。
· 搜索 Telegram 频道在国内需要给 PanSou 配代理（环境变量 PROXY=socks5://…）；只用网站插件的话不需要，来源选「仅网站插件」。
· 插件列表、频道、认证等更多配置见 PanSou 项目的文档。请遵守其「仅供学习研究」的声明。
